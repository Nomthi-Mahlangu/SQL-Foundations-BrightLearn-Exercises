# SQL-Foundations-BrightLearn-Exercises
This repository serves as a comprehensive record of my journey through the SQL Foundations curriculum at BrightLearn. It contains a series of structured exercises designed to master the core principles of relational databases, ranging from basic data retrieval to complex multi-table analysis. Through these challenges, I have refined my ability to write clean, efficient queries and extract actionable insights from structured datasets—a critical step in building a robust technical foundation for Data Science and Machine Learning.
